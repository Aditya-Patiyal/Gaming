# 🎮 Game Hub

A beautiful collection of three classic games with modern, polished UIs.

## 🎯 Games Included

### 1. ♚ Chess
- **Type:** Strategy
- **Mode:** Player vs Player
- **Features:**
  - Full chess rules implementation
  - Move validation and legal move highlighting
  - Castling, en passant, and pawn promotion
  - Move history tracking
  - Player timers
  - Take back move functionality
  - Checkmate and stalemate detection
  - Beautiful dark-themed UI

### 2. 🧠 Color Memory
- **Type:** Memory/Brain Training
- **Mode:** Single Player
- **Features:**
  - Simon Says style gameplay
  - Three difficulty levels (Relaxed, Normal, Blazing)
  - Progressive difficulty as you advance
  - High score tracking (saved locally)
  - Vibrant color animations
  - Score and level tracking
  - Beautiful particle effects

### 3. ✕○ Tic Tac Toe
- **Type:** Classic
- **Modes:** Player vs Player, Player vs AI
- **Features:**
  - Neon-styled UI with smooth animations
  - AI opponent with three difficulty levels (Easy, Medium, Hard)
  - Score tracking across rounds
  - Win line animations
  - Modern gradient effects
  - Responsive design

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. Select a game from the home page
3. Enjoy playing!

## 🎨 Features

- **Modern UI/UX:** Beautiful gradients, animations, and effects
- **Responsive Design:** Works on desktop and mobile devices
- **Easy Navigation:** Return to home page from any game
- **No Dependencies:** Pure HTML, CSS, and JavaScript
- **Local Storage:** High scores and preferences saved locally

- Chrome/Edge (recommended)
- Firefox

## 📝 Notes
